# Metaheurísticas

Implementações de metaheurísticas aplicadas a problemas de otimização combinatória.

```
Metaheuristicas/
└── cvrp/        ← Capacitated Vehicle Routing Problem
    ├── include/ ← Headers (.h)
    ├── src/     ← Código-fonte (.cpp)
    ├── data/    ← Instâncias
    └── results/ ← Saídas
```
